Core Category

Animation

7 checks, listed alphabetically. Open a check for purpose, severity, fix availability, settings and selection behavior.

Action Present

Checks for objects that contain empty animation data. Objects using an Action, NLA strips, or drivers are considered valid.

WarningFix: YesSettings: No

Animated Values

Checks for objects with keyed transform channels where none of the keyed transform values actually change.

WarningFix: YesSettings: Yes

Keyframes in Range

Checks for objects with keyframes before scene start frame or after the scene end frame.

InfoFix: NoSettings: No

Keyframes Present

Checks for objects that have animation data and an assigned Action, but the Action contains no keyframes.

WarningFix: YesSettings: No

NLA Playback Enabled

Checks for objects that contain muted NLA tracks or muted NLA strips.

WarningFix: YesSettings: No

NLA Strips Present

Checks for objects that contain NLA tracks with no strips.

WarningFix: YesSettings: No

Range Boundry Keys

Checks if Animated Objects have Keyframes at Start and End of the Timeline.

WarningFix: YesSettings: No
