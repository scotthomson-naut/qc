Core Category

Materials

6 checks, listed alphabetically. Open a check for purpose, severity, fix availability, settings and selection behavior.

Color Space Valid

Checks image textures used as normal, roughness, metallic, height, displacement, masks, or other non-color data and verifies that their image color space is set to Non-Color.

WarningFix: YesSettings: Yes

Material Assigned

Checks for objects that have missing materials, empty material slots, or faces assigned to invalid or empty material slots.

CriticalFix: YesSettings: No

Material Output Connected

Checks materials for shader nodes that are not connected, directly or indirectly, to an active Material Output node.

WarningFix: NoSettings: Yes

Material Slot Usage

Checks for material slots that are not assigned to any face.

InfoFix: YesSettings: Yes

Material Usage

Checks for unused material datablocks, excluding protected, linked, asset, and Blender-managed materials.

WarningFix: YesSettings: No

Texture Files Exist

Checks if Image texture references a file that doesn't exist on disk

CriticalFix: NoSettings: No
