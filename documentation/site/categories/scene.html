Auto Save Enabled

Checks if Blender's 'Auto Save Temporary Files' preference is enabled, to protect against losing work after a crash or a forgotten manual save.

WarningFix: YesSettings: No

Objects in Collections

Checks if objects are linked directly to the Scene Collection root, bypassing every named collection. Distinct from an object sitting inside a collection that still has Blender's default 'Collection' name - that's still organized, just possibly poorly named. This check is about objects with no organization at all.
