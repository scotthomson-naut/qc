Core Category

Rendering

10 checks, listed alphabetically. Open a check for purpose, severity, fix availability, settings and selection behavior.

Active Single Camera Exists

Checks that the scene has at least one Camera object, that a camera is assigned as the active render camera, and (when the 'Require Single Camera' setting is on) that exactly one Camera object exists.

CriticalFix: YesSettings: Yes

Cycles Denoising Enabled

Checks whether Cycles render denoising is enabled.

WarningFix: YesSettings: Yes

Excessive Render Subdivision

Checks for Subdivision Surface modifiers whose render subdivision level is significantly higher than the configured maximum or the modifier's viewport subdivision level.

WarningFix: YesSettings: Yes

Poly Count Above Limit

Checks whether the scene and individual mesh objects are below configurable polygon limits.

WarningFix: NoSettings: Yes

Render Border Enabled

Checks if Render Border or Crop to Render Region is enabled.

CriticalFix: YesSettings: No

Render Frame Range Mismatch

Checks whether the scene render frame range matches the frame range used by object Actions and NLA strips.

CriticalFix: YesSettings: Yes

Render Resolution Percentage

Checks that the scene render resolution percentage is set to 100%.

WarningFix: YesSettings: Yes

Render Samples Too High

Checks whether Cycles render samples are higher than recommended for the current output resolution.

WarningFix: YesSettings: Yes

View Layer Render Single Disabled

Checks if 'Render Single Layer' is enabled while more than one view layer exists. This scene-wide override skips every view layer except the active one at render time, regardless of each layer's own 'Use for Rendering' setting - usually left on accidentally after fast-iterating on one layer. With only one view layer in the scene, this setting is inert and not flagged.

WarningFix: NoSettings: No

View Layer Rendering Enabled

Checks if every view layer has 'Use for Rendering' enabled. A view layer with this disabled produces zero output when rendering, regardless of whether it's correctly wired into the compositor or has otherwise valid settings - nothing about it ever gets computed at all.

CriticalFix: NoSettings: No
