Color Space Valid

Checks image textures used as normal, roughness, metallic, height, displacement, masks, or other non-color data and verifies that their image color space is set to Non-Color.

WarningAutomatic fix: YesSettings: YesSelection: Object

Why this check exists

This check protects scene quality and helps catch production issues before publishing or rendering.
